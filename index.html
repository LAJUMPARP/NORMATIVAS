🧠 Conceptos RP

❌ MetaGaming (MG)

Usar información externa para beneficiar al personaje dentro del rol.

  • Streams
  • Discord
  • Chats externos
  • Información OOC
✅ PowerGaming (PG)

En LA JUMPA RP el PG está permitido mientras no exista abuso.

❌ Fail RP

Romper el entorno RP de forma intencional.

📌 Normas Generales

🔫 Combate / RDM / VDM
  • Todo combate debe tener contexto.
  • El RDM abusivo está prohibido.
  • El VDM debe justificarse.
🕵️ Rol Criminal
  • Debe existir historia y contexto.
  • No se permite campear zonas ilegales.
  • Las organizaciones tienen límites.
🚓 Rol Policial
  • Debe existir criterio y coherencia.
  • El uso de fuerza debe justificarse.

Zonas Seguras

No está permitido iniciar rol agresivo en estas zonas.
